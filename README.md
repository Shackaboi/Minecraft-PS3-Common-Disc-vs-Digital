# Minecraft PS3 Common (Disk vs Digital)

A small research I've done on the Minecraft PlayStation 3 'Common' Folder



***Conclusion: When playing with BLES or BLUS just delete all in Common/res except for Title Update folder***

***(this may increase ingame performance).***



BLES = BLUS

NPEB = NPUB = NPJB (despite slightly larger tutorial.pck in Common/res/TitleUpdate/GameRules)

**but...**

&#x20;<b>~~Disk~~  =  <del>Digital</del></b>





The reason for this difference is that the disk already has these files so it doesn't need to keep duplicates unlike the digital edition.



BLES and NPEB are taken as examples:



***Difference in:***



**Common/Media/font**:

BLES only has 2= CHS+CHT



**Common/res:**

BLES only has TitleUpdate folder inside (missing everything else)



**Common/res/TitleUpdate:**

BLES has no tutorialDiff \& tutorial.pck



**Common/res/TitleUpdate/res:**



**armor**:

no cloth \& power



**item**:

no book.png



**misc**:

BLES only have beacon\_beam, mapicons, additionalmapicons



**mob**: **BLES is missing 1 folder, 13 files**

1 folder: villager

6 files: all villagers missing

3 files: ender, ender\_eyes, beam

4 files: enderman eyes, red cow, snowman, zombie



**textures**:

no items folder

in block folders missing:

4 files: fire

4 files: lava

2 files: portal



**Unrelated note:** 



you can delete the 8 water MipMapLevel files from original common they are unused and unnecessary.
